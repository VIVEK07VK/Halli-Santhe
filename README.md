# Halli-Santhe Digital 🛒

Halli-Santhe Digital is a modern Hyperlocal Artisan Marketplace Android application designed to connect village artisans and local sellers directly with nearby customers. The platform digitizes traditional local markets by enabling product discovery, order management, secure authentication, and real-time marketplace interaction.

🚀 Getting Started
Prerequisites
Android Studio
Kotlin SDK
Firebase Project
Android Emulator or Physical Device
🔧 Installation
git clone https://github.com/your-username/halli-santhe-digital.git

Open the project in Android Studio.

Sync Gradle files.

Add your google-services.json file inside:

app/google-services.json

Run the application on an emulator or physical device.
